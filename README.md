# SSA 히어로 네트워크

UNKNOWN 세계관의 특수치안관리기구(SSA)가 운영하는 공인 히어로 정보공유 커뮤니티입니다.

## 구현 내용
- 공지·보도자료, 현장 정보, 히어로 커뮤니티, 사건·수배정보, 자료실
- 아이디·비밀번호 가입, 히어로명과 소속 등록
- 서버 저장형 게시글·댓글, 작성자 글 삭제, 검색
- Cloudflare D1 데이터 저장 및 PBKDF2 비밀번호 해시
- UNKNOWN 수배자료와 창작 사건·히어로 게시물

## 개발
Node.js 22.13 이상. `npm ci` 후 `npm run dev`.
D1의 DB 바인딩과 `drizzle/` 마이그레이션 적용이 필요합니다.

## 진행 상태
첫 구현 소스입니다. 작업 환경의 네트워크 오류로 빌드·화면 검증·배포는 아직 완료되지 않았습니다.
공개 운영 전 계정 복구·탈퇴·관리자 도구를 보완해야 합니다.
